# bilingual_demo: a fixed synthetic fixture for the report-language option

This directory is a **software demonstration**, not study data. The matrix is generated by
`generate_fixture.py` from a fixed seed and carries no measured values. Nothing derived
from it may be reported as a result.

It exists for one reason: a Chinese run and an English run have to be executed on exactly
the same matrix, and a follow-up run has to be able to reuse a saved matrix. The released
`minimal_demo` fixture cannot do that, because it is 12 proteins x 8 samples, it contains
missing cells on purpose, and it carries no follow-up state.

## Fixed design

| Property | Value |
|---|---|
| proteins | 24 (`P00001` to `P00024`), positive values, no missing cells |
| samples | 12, `CONT_1`..`CONT_6` and `STIM_1`..`STIM_6` |
| groups | `Control` (6) and `Stimulated` (6) |
| experimental unit | the sample; one donor per sample (`D01` to `D12`) |
| planted effects | `P00007` x2.60, `P00012` x0.45, `P00019` x1.90 on Stimulated |
| seed | 20260921, standard library only, byte-stable reruns |

## Layout

| Path | Purpose |
|---|---|
| `generate_fixture.py` | the generator; reruns are byte-stable |
| `zh_run/` | a Chinese request, for the default `zh` report language |
| `en_run/` | the equivalent English request, for `--report-language en` |
| `en_followup/` | an English follow-up that reuses the `en_run` matrix through `--continue-from` |

The `ProteinQuant.csv` and `SampleInfo.csv` in the three task folders are
**byte-identical**; only `user_input.txt` differs, because the agent reads the task from
that fixed file name.

## Checks that need no model access

    py -3 examples/bilingual_demo/generate_fixture.py
    py -3 scripts/validate_dataset_inputs.py examples/bilingual_demo/zh_run

Running the agent on these folders requires your own model credentials, sends the request to
the endpoint you configure, and may be charged by that provider:

    py -3 main_agent.py -i examples/bilingual_demo/zh_run -rf runs
    py -3 main_agent.py -i examples/bilingual_demo/en_run -rf runs --report-language en
    py -3 main_agent.py -i examples/bilingual_demo/en_followup -rf runs --continue-from runs/RUN
